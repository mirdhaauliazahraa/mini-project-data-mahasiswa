# Mini Project Program Data Mahasiswa

## Deskripsi
Program Data Mahasiswa merupakan aplikasi berbasis Java yang digunakan untuk memasukkan dan menampilkan data mahasiswa, meliputi nama, NIM, dan nilai. Program juga menentukan status kelulusan mahasiswa berdasarkan nilai yang diperoleh.

## Fitur
- Memasukkan nama mahasiswa.
- Memasukkan NIM mahasiswa.
- Memasukkan nilai mahasiswa.
- Menampilkan data mahasiswa.
- Menentukan status kelulusan mahasiswa.
- Mengelola data minimal 3 mahasiswa.

## Konsep yang Digunakan
- Class dan Object
- Variabel dan tipe data
- Input menggunakan Scanner
- Percabangan if-else
- Perulangan (loop)

## File Program
- `Main.java` — program utama untuk memasukkan data dan menjalankan program.
- `Mahasiswa.java` — class untuk menyimpan dan menampilkan data mahasiswa serta menentukan kelulusan.

## Cara Menjalankan
1. Pastikan Java JDK sudah terpasang.
2. Buka terminal pada folder project.
3. Kompilasi program dengan perintah:

   `javac Main.java Mahasiswa.java`

4. Jalankan program dengan perintah:

   `java Main`

## Ketentuan Kelulusan
Mahasiswa dinyatakan **Lulus** jika nilai minimal 60 dan **Tidak Lulus** jika nilai di bawah 60.

## Bahasa Pemrograman
Java
